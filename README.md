## ✨ Features & Highlights

### 🏠 Property & Experience

- **Unobstructed Arabian Sea Views**: Panoramic sunset horizons right from the balcony and bedrooms.
- **Direct Beach Access**: Just 450 meters away from quiet, uncrowded golden sands.
- **Coastal Living Interior**: Inspired by the fishing village of Iddya, decorated with authentic surfboard from *Mantra Surf School (Mulki)*, boat ropes, and coastal textures.

### 📱 Interactive Digital Guest Manual

- **⚡ Instant Quick Search**: Search for Wi-Fi passwords, air conditioning settings, induction hobs, geysers, or nearby food in milliseconds.
- **📋 4-Step Keypad Self Check-In**: Keyless smart door entry guide with Aadhaar/Passport verification checklist.
- **📶 One-Click Wi-Fi Copy**: Instant password copy widget for seamless guest connectivity.
- **📖 6-Step Paginated Stay Guide**:
  - `01/06` The Apartment (Lighting, sliding doors, privacy curtains, lock diagrams)
  - `02/06` The Kitchen (Water purifier 3-step guide, kettle, cooking essentials)
  - `03/06` Cooking & Housekeeping (Induction hob, chimney gesture control, wet/dry waste segregation)
  - `04/06` Comfort & Living (Streaming TV accounts, 24°C–26°C AC settings, 24-hr diesel generator power backup)
  - `05/06` Beach Living (Beach access, sand shower, beach towels & tide safety rules)
  - `06/06` Utilities & Departure (First aid, pharmacies, hospitals, delivery apps, and checkout checklist)
- **🧭 In & Around Mangaluru Guide**: Local fresh catch boat timings (7:30 AM), Mangalorean breakfast spots (Goli Baje, Masala Dosa), iconic seafood (*Giri Manja's*, *Chavadi*), desserts (*Pabbas*), and day trips to Udupi & Kundapura (*Shetty Lunch Home Ghee Roast*).
- **📅 Direct Booking Inquiry**: Formatted WhatsApp booking request generator.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js (v18+) and npm installed on your machine.

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/YOUR_USERNAME/303-oyster-bay.git
   cd 303-oyster-bay
   ```
2. **Install dependencies**:

   ```bash
   npm install
   ```
3. **Start the local development server**:

   ```bash
   npm run dev
   ```

   Open `http://localhost:3000` in your browser to explore the website live!
4. **Build for production**:

   ```bash
   npm run build
   ```

## 🌐 Deployment to GitHub Pages

### Option A: Automatic GitHub Actions (Recommended)

This repository includes a pre-configured `.github/workflows/deploy.yml` workflow.

1. Push your code to the `main` branch.
2. In your GitHub repository, go to **Settings** $\rightarrow$ **Pages**.
3. Under **Build and deployment** $\rightarrow$ **Source**, select **GitHub Actions**.
4. GitHub will automatically build and publish your site!

### Option B: Manual CLI Deploy

```bash
npm run deploy
```
